# Deferred tower concepts

Three legacy tower IDs are preserved only by save migration:

- `decoy` — requires a deterministic targeting-redirection mechanic.
- `mirror` — requires bounded reflection rules with collision-deduplication tests.
- `anonymity` — requires a defined stealth/detection system.

They are not present in the active balance registry, palette, simulator policy, or
new saves. A concept may return only with a complete mechanic, shared runtime and
simulator rules, accessible controls, and automated coverage.
