# Dharmapala Shield - Cybersecurity Defense Game

## Core Concept

Create a tower defense / cybersecurity simulation game where players protect Buddhist meditation technology distribution networks from government intrusion. Players act as “dharmapalas” (spiritual guardians) defending the flow of consciousness-expanding technology to the world.

## Game Mechanics

### Primary Objective

Protect VR headset production facilities and distribution networks from federal agents, hackers, and surveillance systems while maintaining the flow of “Karmic Protocol” devices to enlightenment seekers worldwide.

### Core Gameplay Loop

1. **Network Defense**: Place cybersecurity “shields” (firewalls, encryption nodes, decoy servers) on a grid-based map
1. **Resource Management**: Balance three currencies:
- **Dharma Points** (earned by successful deliveries)
- **Bandwidth** (network capacity for operations)
- **Anonymity** (stealth rating to avoid detection)
1. **Wave Defense**: Incoming threats arrive in waves with increasing sophistication
1. **Distribution Goals**: Successfully route headset shipments to global destinations

### Defense Systems (Tower Types)

- **Firewall Fortress**: Basic blocking defense with Buddhist prayer flag aesthetics
- **Encryption Monastery**: Scrambles data packets with rotating cipher algorithms
- **Decoy Temples**: False targets that misdirect attacks
- **Mirror Servers**: Reflects attacks back to sender using “reflection meditation” concept
- **Anonymity Shrouds**: Cloaks network traffic from surveillance
- **Dharma Distributors**: Boosts delivery speed and success rates

### Enemy Types

- **Script Kiddies**: Fast, weak automated attacks
- **Federal Agents**: Methodical, heavily armored intrusion attempts
- **Corporate Saboteurs**: Target specific production nodes
- **AI Surveillance**: Adaptive enemies that learn from player patterns
- **Raid Teams**: Powerful boss-level coordinated attacks on facilities

## Technical Requirements

### Platform

Browser-based HTML5 game using Canvas or WebGL for smooth performance across devices.

### Visual Style

- **Color Palette**: Deep blues, golds, and whites reminiscent of Tibetan art
- **UI Elements**: Blend cyberpunk aesthetics with Buddhist iconography
- **Grid Map**: Hexagonal network nodes connected by glowing data pathways
- **Animations**: Smooth particle effects for data flow, pulsing meditation-inspired rhythms

### Core Features to Implement

#### 1. Main Game Interface

- Scrollable network map with zoom functionality
- Resource counters prominently displayed
- Placement menu for defense systems
- Wave counter and incoming threat preview
- Real-time network traffic visualization

#### 2. Defense Placement System

- Drag-and-drop tower placement
- Upgrade trees for each defense type
- Range indicators and effectiveness previews
- Cost calculation with resource requirements

#### 3. Enemy Pathfinding

- Multiple route options for attackers
- Dynamic path selection based on defenses
- Speed variations and special abilities
- Boss-level coordinated attack patterns

#### 4. Progression System

- **Campaign Mode**: 15 levels with increasing difficulty
- **Technology Tree**: Unlock new defenses and upgrades
- **Achievement System**: Buddhist-themed accomplishments
- **High Score Tracking**: Global leaderboard integration

#### 5. Educational Elements

- **Tech Tips**: Real cybersecurity concepts explained through Buddhist metaphors
- **Dharma Dictionary**: Clickable glossary of Buddhist terms used in-game
- **Protocol Insights**: Mini-lessons about meditation technology and consciousness

## Audio Design

- **Ambient**: Subtle electronic meditation music with Tibetan singing bowls
- **Effects**: Network pulses, data transmission sounds, alert tones
- **Voice**: Optional narrator explaining cybersecurity concepts in calm, meditative voice

## Specific Implementation Features

### Level Design

- **Tutorial Level**: “Jeta’s Grove Protection” - Defend the retreat center
- **Industrial Level**: “Manufacturing Shield” - Protect headset production
- **Global Level**: “Distribution Network” - Coordinate worldwide delivery
- **Final Boss**: “Federal Shutdown” - Survive massive coordinated attack

### Special Mechanics

- **Meditation Breaks**: Pause periods where players can “meditate” to restore resources
- **Karma System**: Ethical choices affect available defenses and outcomes
- **Enlightenment Mode**: Temporary invulnerability achieved through perfect defense harmony

### Win/Loss Conditions

- **Victory**: Successfully deliver target number of headsets per level
- **Defeat**: Network integrity falls below 25% or key facilities destroyed
- **Bonus Objectives**: Zero detection, perfect efficiency, minimal resource usage
