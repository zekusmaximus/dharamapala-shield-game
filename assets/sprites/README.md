# Entity sprite sheet

`entities.svg` is original project artwork created for Dharmapala Shield. It has a
transparent background and eleven 256×256 source frames in one horizontal row.
Frame names, rectangles, display sizes, and anchors live in
`js/render/SpriteCatalog.js`.

No third-party artwork is included. The repository currently has no top-level
license declaration, so reuse rights for this artwork follow the rights granted
by the project owner rather than an inferred open-source license.
